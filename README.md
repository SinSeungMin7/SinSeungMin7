# 🌿 Git & GitHub Collaboration

팀 프로젝트에서 **기능별 브랜치를 활용하여 개발하고 GitHub 공유 Repository를 통해 팀원들과 코드를 통합**했습니다.

### WorkTopus Branch Workflow

`feature/chat 기능 개발` → `Commit` → `Push` → `develop Merge` → `팀 코드 통합`

### 협업 경험
- `feature/chat` 브랜치에서 담당 기능 개발
- 기능 단위 Commit을 통한 변경 이력 관리
- 원격 Repository에 작업 내용 Push
- Fetch / Pull을 통한 원격 변경 사항 확인 및 반영
- `feature/chat → develop` 브랜치 Merge
- Merge Conflict 발생 시 충돌 파일 확인 및 수정
- GitHub 공유 Repository를 통한 팀 코드 통합 및 협업

# 🎓 Development Background

### Backend Development
Java와 Spring Boot를 기반으로 MVC 구조와 REST API를 학습하고,  
Controller - Service - Repository/Mapper 구조를 활용한 웹 애플리케이션을 구현했습니다.

### Database
Oracle을 중심으로 관계형 데이터베이스 설계와 SQL을 학습하고,  
PK / FK 및 테이블 관계를 고려하여 프로젝트 데이터를 설계했습니다.

MyBatis와 JPA를 각각 활용하여  
SQL Mapper 방식과 ORM 방식의 데이터베이스 연동을 경험했습니다.

### Real-Time Communication
WorkTopus 프로젝트에서 WebSocket, STOMP, SockJS를 활용하여  
HTTP 요청을 반복하지 않고 서버와 클라이언트가 실시간으로 메시지를 송수신할 수 있는 채팅 기능을 구현했습니다.

### AI Integration
Gemini를 프로젝트 기능과 연동하여  
프로젝트 채팅 데이터를 AI가 요약하고 회의록으로 저장할 수 있도록 구현했습니다.

### Git Collaboration
기능별 브랜치에서 개발한 뒤 Commit과 Push를 수행하고,  
develop 브랜치에 Merge하는 방식으로 팀 프로젝트 협업을 경험했습니다.
